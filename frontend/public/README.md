# Favicon Instructions

**To complete favicon setup:**

1. Save the Scient Institute logo image as:
   - `favicon.ico` (for browsers)
   - `favicon.png` (for Apple devices)

2. Place both files in this `public` folder

3. You can convert the image online at:
   - https://favicon.io/favicon-converter/
   - https://convertio.co/png-ico/

The favicon will be automatically served from this directory after deployment.
